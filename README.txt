# 🌱 Трекер привычек

Приложение для отслеживания ежедневных привычек с современным интерфейсом.

## Возможности

- Добавление привычек и отметка выполнения
- Календарь недели с навигацией по прошлым неделям
- Подсчёт серий (streak)
- Система достижений (🌱 🔥 💪 🏆 👑)
- Прогресс-бар выполнения
- Экспорт в CSV
- График активности за месяц
- Тёмная тема Catppuccin Mocha
- Напоминание вечером

## Технологии

Python 3.12+, CustomTkinter, matplotlib, Pillow, JSON.

## Запуск

```bash
pip install -r requirements.txt
python main.py
